# FatBall

FatBall is a free portrait-only 2D football game designed for phones.

## Core direction

- Portrait orientation only
- 3v3 first, with one human controlling one player
- Touch joystick for movement
- Pass, shoot, tackle, sprint and skill controls
- Physics-based loose ball
- Full player customization
- Online room-code multiplayer planned next

## Current prototype

The first build uses AI teammates and opponents so movement, camera, controls and ball feel can be tested before networking is added.

Open `index.html` on a phone browser to play.
